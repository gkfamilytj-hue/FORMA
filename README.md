# FORMA — цифровая платформа (HTML + CSS, без JavaScript)

## Запуск
Распакуйте архив и откройте `forma-tailwind/index.html` в браузере. Для фотографий Unsplash нужен интернет. JavaScript-файлов и подключённых JS-библиотек в проекте нет.

## Разделы
- Главная — описание FORMA, шесть направлений и LED-анимации.
- `about/` — идея и устройство платформы.
- `directions/` — каталог шести направлений.
- `shop/` — товары и переход к форме заказа по email.
- `games/` — игровые жанры, CSS-викторина и форма предложения игры.
- `proposals/game/` — заявка для разработчиков игр.
- `proposals/brand/` — заявка для брендов и поставщиков товаров.
- `earn/`, `company/`, `movies/`, `social/` — дополнительные тематические страницы.
- `search/` — полный каталог ссылок по сайту.
- `services/`, `work/`, `contact/` — услуги, портфолио и контакты.

## Без JavaScript
Переходы, кнопки-ссылки, мобильное меню (`details`), CSS-анимации, LED-свечение, CSS-викторина и светлая/тёмная тема через CSS checkbox работают без JavaScript. Для поиска по каталогу используйте Ctrl+F / Cmd+F на странице `search/index.html`.

Формы предложения игры, бренда и контактов используют `mailto:hello@example.com`: отправка откроет установленное почтовое приложение. Замените адрес `hello@example.com` на реальный адрес владельца сайта.

## Что требует серверной части
Автоматическое сохранение заявок на сайте, настоящие аккаунты, общая база пользователей, модерация предложений, синхронизированная корзина и онлайн-оплата, живая лента и полноценный поиск по всем страницам требуют backend, базы данных и защищённой авторизации. В этой версии такие функции не имитируются как работающие.

## Технологии
HTML5, CSS3, CSS Grid/Flexbox, SVG, `details/summary`, нативные HTML-формы.
